360 Panoramic · HDRI Environment Builder

01 · Source

Radiance .hdr and OpenEXR .exr are treated as editable linear-radiance sources. HDR import accepts RGBE or XYZE with modern RLE and legacy/raw scanlines. EXR import accepts OpenEXR file-format v2 single-part scanline or one-level tiled RGB/RGBA/Y files using HALF, FLOAT, or UINT channels with NONE, ZIP, ZIPS, or PIZ compression. Files created by newer OpenEXR software remain compatible when they use this standard v2 file format and supported features. Tone mapping is display-only.
Source projection: Equirectangular 360° × 180° only. A 2:1 source is recommended for full spherical coverage.
The 360 pipeline now accepts equirectangular source mapping only. Browser-friendly preview stays lightweight while export uses the original source up to the graphics device limit.

HDRI Pipeline Status

Source interpretation and export information
Geometry: source interpretation and HDR/EXR/PNG export are equirectangular 360° × 180° only, with an exact 2:1 master map.
Radiance: bitmap RGB is linearized before processing; Radiance .hdr and OpenEXR .exr are decoded as scene-linear radiance. ACES-style tone mapping is used only for on-screen preview. HDR exports use RGBE; EXR exports use linear HALF RGB.
Lighting Test: the preview evaluates the environment on chrome and diffuse test spheres plus a neutral ground surface so directionality, reflections, color cast, and headroom can be inspected before export.
